# Codex Light 外网连接方案

当前版本支持局域网 HTTPS。外网连接是后续开发方案，本版本没有部署中继或改变本机防火墙。

## 推荐：应用内中继与端到端加密

电脑守护服务和 Android 客户端各自通过 WSS 主动连接中继。中继按设备与连接标识转发加密数据；电脑继续持有 Desktop 会话，模型、工具、审批和文件处理仍在电脑执行。手机不用占用 Android 的 VPN 连接。

配对采用电脑确认的设备公钥与二维码，支持查看和撤销设备。现有八位配对码仅用于局域网配对；公网连接使用独立设备凭证、短期令牌、消息签名与防重放序号。加密层使用经过审查的协议和实现，不自行设计密码算法。中继只能处理路由、连接状态和限流信息，不能读取消息或附件正文；路由元数据依然可能暴露设备在线时间与通信大小。

断线恢复包含请求编号、确认回执与事件游标。读操作可以恢复并重试；发送、回答提问和立即引导以同一操作编号查询结果，避免因网络重连再次提交。网络切换后恢复同一会话，不重新创建聊天。附件采用分块加密、大小限制和完整性校验。

实施分三步：先为现有局域网 HTTP 客户端抽象传输层并完成幂等回执持久化；再增加中继、设备密钥与撤销机制；最后验证 Wi-Fi/蜂窝切换、双方休眠、进程重启、长时间离线与附件恢复。中继地址、托管服务、费用及账户由部署阶段确定。中继流量本身不调用模型；正常发送仍按现有 Codex 账户计量。

## 快速试验选项

| 方案 | 需要的开发 | 适用条件 |
| --- | --- | --- |
| Tailscale 私有网络 | Android 地址校验增加明确允许的覆盖网地址；电脑证书添加对应 SAN；服务 Host 校验同步更新 | 可以在手机安装并使用额外网络客户端。当前 App 尚不接受其覆盖网地址。 |
| Cloudflare Tunnel 与 Access | 新增公网传输、身份认证与访问控制；隔离本机管理接口；处理新的 TLS 信任方式 | 有合适的账户和域名，接受此方式的运维要求。Tunnel 提供传输，不自动提供消息端到端加密。 |
| 应用内加密中继 | 传输抽象、中继、设备密钥、撤销、恢复与附件协议 | 日常使用，希望在 App 内完成连接，并保留现有手机网络配置。 |

Tailscale 的个人方案当前列为免费，包含六位用户和不限数量的用户设备；实际使用范围以其官方条款为准。[官方价格](https://tailscale.com/pricing)

Cloudflare Tunnel 使用电脑发起的出站连接，无需为电脑配置公网 IP。[官方说明](https://developers.cloudflare.com/cloudflare-one/networks/connectors/cloudflare-tunnel/)

公网网关只能暴露已认证的会话接口。本机预览端口 8788、配对码查询、修改连接来源和修改配对码等管理接口必须留在电脑；反向代理进入本机时可能被现有服务识别为本机请求，不能直接公开转发整个预览服务。

当前 Android 包名、应用签名与更新入口可保持兼容，传输方式作为连接设置增加。部署前需要验证授权、撤销、重放、重连和升级恢复，再接入真实聊天。
