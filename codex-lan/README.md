# Codex Light 电脑服务

原生 Android 与手机网页通过电脑连接服务接入 Codex Desktop 的原有聊天。桌面继续负责模型、工具和任务执行。

新用户请先阅读 [首次使用](GETTING-STARTED.md)，完成自己的电脑服务、连接来源与手机证书配置。

## 运行

完整 Windows 安装包：解压后双击 `install.bat`，自动安装电脑服务和 Codex Light 插件。包内自带 Node.js，无需另装 OpenSSL。源码安装需要 Node.js 22 或更新版本，以及已打开的 Codex Desktop。

```powershell
./install-keepalive.ps1
```

电脑打开 http://127.0.0.1:8788，查看局域网 HTTPS 地址和本次配对码。手机连接同一局域网，信任本机生成的公开证书后，打开地址并输入配对码。可添加到手机主屏幕。需要信任的公开证书是 `.runtime/cert.pem`，私钥 `.runtime/key.pem` 仅保留在电脑。

安装脚本注册当前 Windows 用户的任务计划程序任务 `CodexLAN-<目录哈希>`，以普通用户权限运行 `watch.mjs`。任务在登录时启动，服务退出后约 3 秒重启。聊天回复结束不影响运行；电脑关机、注销或休眠时连接中断。Codex Desktop 关闭时服务保留，桌面重新打开后重新发现本地通信端点。任务信息保存在 `.runtime/keepalive.json`，日志在 `.runtime/watch.log`。

一次性调试可运行 `./start.ps1 -Foreground`。常驻运行使用守护任务；仅用 `start.ps1` 启动的服务没有独立守护任务。

修改配对码：在电脑面板点击“连接设置”，输入新的 8 位数字并保存，或点击“随机生成”。设置保存在 `.runtime/config.json`，重启后仍有效；现有已配对设备保持连接。新设备需使用新码。此设置仅限电脑本机页面访问。

若未自动取得连接来源聊天 ID，在电脑连接面板填写一条本机 Codex 聊天的 ID 并保存。这是桥接调用的来源标识；手机选择的目标聊天仍是对应的桌面原有聊天。设置保存在 `.runtime/config.json` 供下次启动使用。

停止服务并禁用登录自启动：

```powershell
./stop.ps1
```

再次运行 `./install-keepalive.ps1` 可恢复守护任务和登录自启动。

完整 Windows 安装器通过单独 Windows 权限提示配置防火墙：仅允许捆绑 Node 的 TCP 8787 专用网络、本地子网入站。源码启动脚本不添加规则。手机不可访问时检查防火墙和 Wi-Fi 客户端隔离。

## 功能与边界

- 列出桌面本机最近 50 条聊天及置顶聊天，搜索并选择原有聊天。已配对的 `/api/threads` 保留真实 `projectId`，并提供本机项目的 ID、保存名称和根目录；无项目归属保持为空。项目元数据缓存 60 秒，读取失败保留上次成功的元数据并返回提示，聊天列表继续可用。
- 读取消息、已记录的进度、工具执行记录和状态；前台约每 1.2 秒刷新，支持加载更早记录。
- 通过桌面 `send_message_to_thread` 接口向原有聊天提交手机输入，可携带可用模型和推理强度。已配对的 `/api/models` 从本机发送接口读取模型目录与每模型支持的强度，缓存 60 秒，手动刷新最短间隔 5 秒。提交时验证模型/强度组合，发送去重绑定模型选项；省略选项保留桌面当前设置。运行中消息的处理方式由桌面决定。
- 配对码、12 小时会话、HTTPS、跨站请求检查、接口白名单、发送频率限制及持久化发送去重。凭证的哈希与有效期保存在 `.runtime/sessions.json`，服务重启保留有效登录；注销和过期后需重新配对。
- 标题、列表、加粗和代码显示；桌面附带的浏览器及附件上下文可展开查看。
- Android 0.3.0 使用已配对的 `/api/images/<引用>` 查看会话图片。服务器仅登记会话附件和 Markdown 图片，校验实际文件格式与 20 MB 上限，不开放任意文件路径。支持 PNG、JPEG、GIF、WebP、BMP；本地文件删除后返回明确提示。引用随服务启动重新生成，客户端刷新会话取得新引用。
- 已配对的 `/api/usage` 读取账户剩余用量，优先采用多额度窗口数据；剩余比例为 `100 - usedPercent`，限制在 0–100。缺失值保留为 null。仅返回窗口、剩余比例、重置时间及额外 credits，不转发账户 ID 或额度重置凭证。读取合并并缓存 60 秒，手动刷新最短间隔 5 秒。

目前桌面接口返回消息快照；逐字增量输出与审批响应接口尚未接入。遇到需要审批的任务，仍需在桌面处理。手机后台刷新受系统限制，回到前台会重新读取。

桥接使用 Codex Desktop 的内部本地命名管道。这不是公开稳定的第三方 API，桌面更新可能改变协议。服务在启动时检查接口，桌面退出或接口变化时报告连接错误。聊天列表和读取不会启动独立的 Codex app-server，也不会恢复聊天取得写入权。

发送超时可能发生在桌面已经收到消息之后。服务先记录请求再提交，重复请求不重复转发；结果未知时保留状态供核对。勿删除 `.runtime/receipts.json` 来重试不确定的消息。界面发送按钮不自动重试。

## 本地文件

应用代码在本目录；`.runtime/` 保存机器配置、证书私钥、配对信息、日志与发送回执。分发源代码时排除 `.runtime/`。仅服务的固定接口对手机开放，不开放任意工具调用、文件路径或命名管道地址设置。

## 验证

```powershell
npm test
```

自动测试使用模拟桌面，覆盖认证、跨站请求、接口边界、消息去重和管道帧处理。真实桌面的只读联调与手机实机联调分别记录在 `VALIDATION.md`。

## 手机附件与权限入口

0.4.5 新增已配对的 `POST /api/threads/{id}/uploads?requestId={uuid}&name={filename}`，请求体为文件原始字节，携带会话 Cookie 和 CSRF。只接受本机可见的已有会话；单文件 20 MB，每条最多 5 个且总计不超过 40 MB。上传按会话绑定 UUID，校验名称与 SHA-256，重复编号与不同内容冲突。全局最多同时处理 2 次上传，单会话登录每分钟最多 10 次；电脑附件总空间最多 512 MB、2048 个附件。

文件保存在 `.runtime/uploads/`，索引持久化，聊天发送携带 `attachments` 编号列表。服务验证文件与目标会话一致、内容未变，再将文件路径加入附件上下文，通过原有发送接口提交。发送回执绑定正文、模型及附件顺序，结果不明时不自动重发。手机移除草稿附件只移除下一条消息的引用；电脑文件继续保留，以便读取历史。

上传图片仅通过已配对的 `/api/upload-images/{threadId}/{id}` 读取，依据文件内容识别格式，不接受任意文件路径。其他附件交由 Codex 从已上传的本地文件读取；服务不执行文件。源码包和 Git 忽略 `.runtime/`，不会发布附件、凭证或运行记录。需清空附件空间时，停止服务后备份并移除 `.runtime/uploads/`，再启动服务；历史附件将不可用。

`GET /api/threads/{id}/permissions` 明确返回 `editable:false`，当前桥接工具不开放权限修改。已配对的 `POST /api/threads/{id}/open-desktop` 仅导航电脑窗口到已有会话，供使用 Desktop 盾牌修改权限；不创建会话。


## 0.4.7 会话互动

应用名称为 Codex Light，包名与发布签名保持兼容，支持覆盖安装。有待回答问题或排队消息时，聊天页显示“会话互动”入口。Plan 的 `request_user_input` 与 MCP 表单提问使用 Desktop 原始请求编号提交，保留数字与字符串 ID 的区别；支持选择、文字、布尔、数字及枚举多选。MCP 可拒绝回答或取消提问，URL 等不支持的模式提供电脑处理入口。需要电脑服务 0.4.7。

“立即引导”读取 Desktop 已保存的排队消息，在正在运行的轮次提交原文字与原消息 ID，收到成功结果后通过 Desktop 移除原排队项。当前支持纯文字本地队列；附件、服务端队列和 Desktop 禁止立即发送的消息需在电脑处理。重复请求使用相同操作编号，提交结果不确定时应先刷新核对。

服务在 Desktop 重启后重新发现仍存活的本地端点，启动日志不可用时以只读能力检查识别接口。活跃的配对连接每小时续期，闲置十二小时后需重新配对。服务重启保留有效的配对凭证、草稿和附件。

外网连接方案见 [REMOTE-ACCESS.md](REMOTE-ACCESS.md)，推荐应用内中继与端到端加密；本版本没有部署外网连接。
